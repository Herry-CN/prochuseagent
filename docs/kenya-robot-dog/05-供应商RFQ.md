## 3. 必须书面澄清的问题

1. 宣传续航是否含云台、4G、夜间灯光？
2. 雨天、积水、扬尘的真实限制？
3. 软件是买断还是必须年费？停服后机器能否离线巡检？
4. 肯尼亚时区远程支持如何安排？
5. 电池、足垫、关节的建议年消耗量？
