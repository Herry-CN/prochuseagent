# 场景用例与验收标准

> 受众：客户可见，并作为试点和合同附件。
> 上游：`02-客户需求规格书.md`
> 下游：客户方案书、试点范围、FAT/SAT验收

每个场景必须能在现场演示。无法演示的能力不要写进方案书。

## 场景 A：夜间周界巡更

- **对应需求：** M1
- **前置：** 路线已建图，充电舱在线
- **步骤：** 一键启动 → 按点位巡检 → 低电回充 → 自动续巡
- **通过标准：** 连续 __ 夜按设定间隔完成巡更，中断次数 ≤ __
- **失败标准：** 频繁卡住、无法回充、路线偏离

## 场景 B：人员入侵告警

- **对应需求：** M2、S1
- **步骤：** 测试人员进入指定区 → 机器狗发现 → 值班室收到画面和位置
- **通过标准：** 夜间指定距离内检出；误报率在商定范围内
- **失败标准：** 明显人员漏报，或告警无法定位

## 场景 C：远程喊话驱离

- **对应需求：** M3
- **步骤：** 值班员看到告警后对目标喊话
- **通过标准：** 目标位置可听清预设英文/斯瓦希里语内容
- **失败标准：** 无声、严重延迟、无法指向目标

## 场景 D：与门卫协同

- **对应需求：** M2、人机协同
- **步骤：** 告警 → 门卫按SOP出警 → 机器狗保持观察或跟踪
- **通过标准：** 门卫能在 __ 分钟内根据告警到达
- **失败标准：** 告警无位置、保安看不懂界面

## 场景 E：断电/断网降级（如列为Must才验收）

- **步骤：** 模拟断网或市电中断
- **通过标准：** 本地继续巡检或安全回舱；来电后恢复
- **失败标准：** 当场瘫痪且无法找回
