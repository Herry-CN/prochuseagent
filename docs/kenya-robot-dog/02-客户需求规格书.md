## 1. 项目目标（一句话）

用机器狗在指定场地进行定时/定点巡检，发现异常后告警并支持远程查看与喊话，由现有保安完成处置。

## 2. 需求分级

只把真正不做就不买的内容放进 Must。Should 可进标准档，Could 只进旗舰档。

| ID | 需求 | 等级 | 可验收指标 | 来源 |
| --- | --- | --- | --- | --- |
| M1 | 夜间周界巡检 | Must | 指定路线每 __ 分钟重访一次；连续值守 __ 小时 |  |
| M2 | 发现人员/车辆并告警 | Must | 夜间 __ 米内发现人体；告警推到值班室小于 __ 秒 |  |
| M3 | 远程查看与喊话 | Must | 值班室能看实时画面并喊话 |  |
| M4 | 自动回充并继续任务 | Must | 低电自动回舱，充满后恢复巡检 |  |
| M5 | 适应当地气候与路面 | Must | 工作温度、防尘防水、指定路面可通过 |  |
| S1 | 热成像 | Should | 无照明条件下识别人体 |  |
| S2 | 与现有监控平台对接 | Should | 告警进入现有VMS/电视墙 |  |
| S3 | 电子围栏/禁入区 | Should | 进入禁区自动告警 |  |
| C1 | 气体/烟雾等额外传感 | Could |  |  |

## 4. 明确不做

- 不替代持械处警或抓捕。
- 不承诺识别所有伪装/遮挡目标。
- 不在未勘查的软泥、深积水、密集铁丝网区域运行。
- 不在URS确认前锁定品牌与最终价格。
