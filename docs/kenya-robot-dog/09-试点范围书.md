# 试点范围书

> 受众：客户。肯尼亚首单默认先试点，再按测算台数扩容。
> 上游：URS Must 中可演示的 2–3 个场景
> 下游：试点合同、正式方案与报价

## 1. 目的

在真实场地上验证机器狗能否按约定间隔巡检、夜间发现目标、回传告警并自动回充，作为全场采购依据。

## 2. 范围（写死）

| 项 | 内容 |
| --- | --- |
| 场地 | 仅 __ 区域，路线约 __ km |
| 设备 | 1 台机器狗 + 1 套载荷 + 1 个充电舱 + 1 个值守端 |
| 周期 | __ 天（建议 30–90 天） |
| 值守 | 客户提供值班人员；我方提供操作培训 |
| 验收场景 | 场景A 巡更、场景B 告警、场景C 喊话（见用例文件） |
| 不包含 | 全场覆盖、与全部旧系统对接、24小时无人值守承诺 |

## 3. 双方责任

**我方：** 到货或远程指导安装、建图、培训、远程支持、问题记录。
**客户：** 供电、网络、场地安全、夜间陪同、按SOP处警、不把设备开出约定区域。

## 4. 通过后如何扩容

试点通过后，按已确认的标准档 BOM 和锁定单价，在 __ 日内下全场订单。未通过则按合同退还/买断试点设备，不自动进入全场承诺。

## 5. 成功/失败判定

沿用 `03-场景用例与验收.md`。额外记录：卡住次数、回充失败次数、误报、客户值班员能否独立操作。
